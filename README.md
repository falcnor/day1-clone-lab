# day1-clone-lab

This is a **practice clone** for [Day-1 Project OS](https://start.printstack.app) buyers — a tiny public repo so you can try `git clone` without touching your real project.

It is **not** the paid pack. You will not find prompts, workflow docs, or the full starter here.

## What to do after you clone

1. Clone this repo into a folder **beside** your unzipped project (sibling folder), as Phase 2 in your pack describes.
2. Copy **`CONTINUE.md`** from this repo into your project root (next to `START_HERE.md`).
3. Open `CONTINUE.md` in Cursor (or any editor) and follow it into **Phase 3**.

That’s the whole lab.
